# LeetCode Solutions

My personal solutions to [LeetCode](https://leetcode.com/) problems, written for practice and review. All code here is my own work.

## Structure

Problems are grouped by their main topic. Each problem lives in its own folder named `<number>-<slug>`, matching the problem's URL on LeetCode:

```
hash-table/
└── 0001-two-sum/
    ├── solution.py   # my solution
    └── README.md     # short summary, idea
```

Each problem's `README.md` has a link to the original statement, a brief description in my own words, the approach, and time/space complexity.
